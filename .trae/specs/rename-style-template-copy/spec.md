# 风格模板文案改为提示词文案 Spec

## Why
当前「风格模板」功能实质是管理图片/视频生成用的提示词模板（人物/场景/物品/故事板图片提示词）及配套参考图，供各企划选用。但「风格模板」「风格设定」等文案未体现其「关于提示词」的核心功能，容易让用户误解为纯视觉风格配置。需将面向用户的文案改为「提示词」相关表述，使其与功能一致。

## What Changes
- 将「风格模板」相关 UI 文案统一改为「提示词管理」（页面入口/标题）与「提示词模板」（指代单个模板）。
- 将「风格设定」相关 UI 文案统一改为「提示词设定」。
- 将「风格参考图/风格参考」徽标与开关文案改为「提示词参考」，与提示词语境一致。
- 将新建模板默认名「新风格」改为「新提示词」，名称占位符「风格名称」改为「提示词名称」，描述 hint「该风格的特色」改为「该提示词的特色」。
- 同步更新引用上述名称的说明条、空状态、删除确认、弹框标题等衍生文案。

**不改动（明确排除）：**
- 内部标识符：变量名（`styleTemplate`、`seriesStyleSettings` 等）、类型（`StylePreset`、`StyleSettings`）、路由路径（`/style-templates`、`/series/[id]/style-settings`）、API 路径（`/api/settings/style-templates`）、存储 key（`style-templates`）。
- 代码注释。
- LLM 上下文文本：`styleToText` / `styleTemplateForType` 生成的「当前风格设定：…」「【人物图片提示词模板】…」等发送给模型的提示文本（避免影响生成行为）。
- 默认预设数据内容（如 `cg超写实动漫风格` 等用户可见的预设名称/描述，属数据非标签）。
- 各模板字段标签「人物/场景/物品/故事板图片提示词模板」（已含「提示词」，准确无需改）。

## Impact
- Affected code:
  - `app/style-templates/page.tsx`（主页面：标题、说明条、列表标签、删除提示、占位符、参考图徽标、弹框标题）
  - `app/series/[id]/style-settings/page.tsx`（选择页：标题、说明条、空状态、链接文字、选择标签）
  - `app/page.tsx`（首页导航按钮）
  - `app/episode/[id]/page.tsx`（菜单项：风格模板、风格设定）
  - `components/ImageGenerationDialog.tsx`（参考图开关文案、徽标）
  - `lib/style-settings.ts`（`createEmptyTemplate` 默认名 `新风格`）
- 不涉及路由、API、存储结构变更，无数据迁移，无破坏性变更。

## ADDED Requirements

### Requirement: 提示词管理命名
系统 SHALL 在所有面向用户的 UI 文案中，以「提示词管理」指代原「风格模板」页面/入口，以「提示词模板」指代单个模板条目。

#### Scenario: 首页与菜单入口
- **WHEN** 用户在首页或剧集页菜单查看入口
- **THEN** 原「风格模板」入口显示为「提示词管理」

#### Scenario: 提示词管理页面标题与说明
- **WHEN** 用户进入提示词管理页面
- **THEN** 页面标题为「提示词管理」，副标题与说明条使用「提示词模板」「提示词设定」表述，不再出现「风格模板」「风格设定」

#### Scenario: 列表与删除确认
- **WHEN** 用户查看模板列表或删除模板
- **THEN** 列表标签为「提示词模板列表」，删除提示文案为「至少需要保留一个提示词模板…」「确定删除该提示词模板？…」

#### Scenario: 新建模板默认名
- **WHEN** 用户新建一个模板
- **THEN** 默认名称为「新提示词」，名称输入框占位符为「提示词名称」，描述 hint 为「简短说明该提示词的特色」

### Requirement: 提示词设定命名
系统 SHALL 在所有面向用户的 UI 文案中，以「提示词设定」指代原「风格设定」页面/入口。

#### Scenario: 剧集菜单与页面标题
- **WHEN** 用户在剧集页菜单或进入企划选择页
- **THEN** 菜单项与页面标题显示为「提示词设定」，选择标签为「选择提示词」

#### Scenario: 说明条与空状态
- **WHEN** 用户查看提示词设定页说明条或空状态
- **THEN** 说明条引导前往「提示词管理」页面；空状态提示「暂无提示词模板，请先前往「提示词管理」页面创建。」

### Requirement: 提示词参考命名
系统 SHALL 将原「风格参考图/风格参考」相关 UI 文案改为「提示词参考」。

#### Scenario: 参考图徽标与状态
- **WHEN** 用户在提示词管理页或图片生成弹框中查看已设置的模板参考图
- **THEN** 徽标显示「提示词参考」，状态文字为「已设为提示词参考」

#### Scenario: 图片生成弹框参考图开关
- **WHEN** 用户在图片生成弹框中查看模板参考图开关
- **THEN** 开关文案为「使用参考图（提示词参考）」

#### Scenario: 参考图生成弹框标题
- **WHEN** 用户从提示词管理页打开参考图生成弹框
- **THEN** 弹框标题为「生成参考图」
