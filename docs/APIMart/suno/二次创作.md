# 灵感生成 (inspo)

>  - 用 1–4 段公网音频作为灵感参考生成新歌（直接给音频 URL，不走 task_id）。
- 异步任务：提交返回 `task_id`，轮询 `GET /v1/music/tasks/:task_id` 获取结果

## Body

<ParamField body="model" type="string" default="suno">
  音频模型。当前传 `suno`（不传默认 `suno`）。
</ParamField>

<ParamField body="audio_urls" type="array" required>
  1–4 个可公开访问的音频 URL 数组。
</ParamField>

<ParamField body="version" type="string" default="v5.5">
  生成版本：`v4` / `v4.5` / `v4.5+` / `v4.5-all` / `v5` / `v5.5`，影响音质与计费；不传默认 `v5.5`。
</ParamField>

<ParamField body="prompt" type="string">
  歌词 / 内容。
</ParamField>

<ParamField body="title" type="string">
  标题。
</ParamField>

<ParamField body="tags" type="string">
  风格标签。
</ParamField>

<ParamField body="negative_tags" type="string">
  排除的风格标签。
</ParamField>

<ParamField body="style_weight" type="number">
  风格权重，`0.00`–`1.00`。
</ParamField>

<ParamField body="weirdness_constraint" type="number">
  创意度权重，`0.00`–`1.00`（别名 `weirdness`）。
</ParamField>

<ParamField body="audio_weight" type="number">
  音频权重，`0.00`–`1.00`。
</ParamField>

<ParamField body="vocal_gender" type="string">
  人声性别：`Male` / `Female`。
</ParamField>

<ParamField body="auto_lyrics" type="boolean">
  `true`=对输入歌词进行二次创作。
</ParamField>

<Note>
  **获取结果**：本接口为异步任务。提交后拿到 `task_id`，按 3–5s 间隔轮询 `GET /v1/music/tasks/{task_id}`，直到 `status` 为 `completed` 或 `failed`（音乐生成通常 30–120s；生成中为 `pending`，`progress` 排队 10 → 就绪 50 → 完成 100）。完成后在 `data.result.music[]` 取 `audio_url`。失败时 `data.error.message` 为原因，自动退回预扣额度。
</Note>
