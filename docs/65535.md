1. 概述
图片生成是长耗时操作(单张数十秒,多张/高分辨率更久),为避免 HTTP 连接长时间挂起或超时,本服务采用异步队列模型。你有两种接入方式:

方式	端点	适合场景
OpenAI 兼容(推荐)	POST /v1/images/generations、/v1/images/edits	已有 OpenAI Images 代码,几乎零改动直接用;支持同步等待 / 流式 / 异步三种模式
原生异步任务 API	POST /v1/images/async-generations 等	想显式拿 job_id、自己轮询或用回调、管理任务列表
两者底层是同一个队列。结果图存对象存储,以 URL 形式返回(有有效期,见限制,请及时下载)。

2. 鉴权
所有请求头带 API Key:

Authorization: Bearer <YOUR_API_KEY>
⚠️ 你的 API Key 必须已开通图片生成权限(归属图片分组),才能调用异步图片接口。无权限的 Key 调用会返回 403。

3. 方式一:OpenAI 兼容接口(推荐)
与标准 OpenAI Images API 调用方式完全一致,只是底层改成异步。通过请求头/参数选择三种返回模式。

3.1 端点
Method	路径	Body
POST	/v1/images/generations	JSON
POST	/v1/images/edits	multipart/form-data(image、可选 mask、prompt…)
3.2 请求体(generations,JSON)
{
  "model": "gpt-image-2",
  "prompt": "a red apple on a white table, photorealistic",
  "size": "2048x2048",
  "quality": "high",
  "n": 1,
  "response_format": "url"
}
字段	必填	说明
prompt	✅	提示词,空则 400
model		缺省为 gpt-image-2
size		见档位;默认与上游一致
quality		透传上游 *见备注
n		张数 *见备注
response_format		url(默认)或 b64_json。b64_json 时返回里额外带 base64
当前quality/n无论传入什么参数，始终会传递为auto和1

3.3 三种返回模式
(a) 同步等待(默认)
不带 X-Async-Mode、不带 stream → 服务端阻塞轮询直到完成,最多 5 分钟,返回标准 OpenAI 格式:

{
  "created": 1748846400,
  "data": [
    { "url": "https://image.65535.space/jobs/img_xxx/0.png" }
  ]
}
response_format=b64_json 时,每项额外含 "b64_json": "...."。
超过 5 分钟未完成 → 504(任务仍会在后台跑完,可改用异步模式或之后用 job_id 查)。
任务失败 → 502,body {"error":{"type":"upstream_error","code":"...","message":"..."}}。

(b) 异步模式(X-Async-Mode: true)
立即返回 202,不等待:

{
  "job_id": "img_3f2a...c1",
  "status": "pending",
  "status_url": "/v1/images/async-generations/img_3f2a...c1",
  "created": 1748846400
}
随后用 GET /v1/images/async-generations/{job_id} 轮询,或配 回调。异步模式没有 5 分钟等待窗口,任务跑到完成为止。

(c) 流式("stream": true)
在 JSON body 里加 "stream": true → 返回 SSE(text/event-stream)。等待期间每 10 秒发一行 : keepalive 注释保活;完成时每张图发一个事件,最后 [DONE]:

: keepalive

event: image_generation.completed
data: {"type":"image_generation.completed","b64_json":"...","url":"https://...","created_at":1748846400,"size":"2048x2048"}

data: [DONE]
失败:event: error + data: {"error":{"type":"upstream_error","code":"...","message":"..."}}。
超时(5 分钟):event: error + data: {"error":{"type":"timeout",...}}。

4. 方式二:原生异步任务 API
返回统一包络 { "code": 0, "message": "success", "data": <对象> }(失败时 code 非 0、message 为错误描述)。

Method	路径	用途
POST	/v1/images/async-generations	提交任务,返回 Job 对象(立即返回,不等待)
GET	/v1/images/async-generations/{job_id}	查询单个任务
GET	/v1/images/async-generations?status=&page=&page_size=	我的任务列表(分页)
请求体同 3.2(OpenAI Images 格式)。

4.1 Job 对象
{
  "code": 0,
  "message": "success",
  "data": {
    "job_id": "img_3f2a...c1",
    "status": "pending",
    "model": "gpt-image-2",
    "prompt": "...",
    "size": "2048x2048",
    "quality": "high",
    "n": 1,
    "image_count": 0,
    "image_size_tier": "",
    "result_urls": [],
    "error_code": "",
    "error_message": "",
    "cost_usd": 0,
    "created_at": "2026-06-04T10:00:00Z",
    "started_at": null,
    "finished_at": null,
    "expires_at": "2026-06-05T10:00:00Z",
    "retry_count": 0,
    "upstream_ms": 0
  }
}
字段	说明
job_id	任务 ID(img_ + 32 字符),后续查询/回调用
status	pending 排队 / running 生成中 / done 成功 / failed 失败
image_count	成功出图数量
image_size_tier	计费档位 1K/2K/4K(完成后写入)
result_urls	结果图 URL 数组(成功后填充,有有效期)
error_code / error_message	失败原因(见错误处理)
cost_usd	本次实际计费(USD)
created_at / started_at / finished_at / expires_at	时间戳(RFC3339)
retry_count / upstream_ms	诊断信息(重试次数 / 上游耗时 ms)
4.2 轮询建议
提交后轮询 GET /v1/images/async-generations/{job_id},直到 status 为 done 或 failed。建议间隔 1–3 秒,设置合理的最大等待。done 后从 result_urls 下载图片。

5. 请求头总览
所有提交端点(generations / edits / async-generations)通用:

Header	取值	说明
Authorization	Bearer <key>	必填
X-Async-Mode	true	(仅 generations/edits)立即返回 job_id,不等待
X-Async-Image-Callback-Url	http(s) URL(≤2048)	任务终态后 POST 通知此地址(见回调);非法 → 400
X-Async-Image-No-Retry	1/true/yes	失败不自动重试(默认会按平台策略重试可恢复错误)
X-Async-Image-Max-Queue-Sec	秒(数字)	客户端侧限流:若当前平均排队时长超过该值,提交直接被拒(503 queue_too_long),用于你按负载主动退避
X-Async-Image-Main-Model	模型名	(高级)覆盖编排模型
X-Async-Image-Effort	minimal/low/medium/high/xhigh	(高级)覆盖推理强度
编排模型与推理强度自定义当前未全量开放，如有需求请联系客服

6. 回调(Webhook)
不想轮询时,提交请求带:

X-Async-Image-Callback-Url: https://your-server.com/hooks/image-done
任务到达**终态(done/failed)**后,服务端会向该地址 POST 一个 JSON:

{
  "request_id": "img_3f2a...c1",
  "status": "done",
  "model": "gpt-image-2",
  "size": "2048x2048",
  "image_count": 1,
  "result_urls": ["https://image.65535.space/jobs/img_3f2a...c1/0.png"],
  "error_code": "",
  "error_message": "",
  "cost_usd": 0.18,
  "created_at": "2026-06-04T10:00:00Z",
  "finished_at": "2026-06-04T10:00:42Z"
}
请求头:

Content-Type: application/json
User-Agent: sub2api-async-image-callback/1
注意
回调是 best-effort:你的接收端应返回 2xx;非 2xx 视为失败(平台会尝试多个出口,但不保证最终送达)。
回调可能因网络/出口策略而失败或延迟;关键业务请同时保留轮询兜底,或对同一 request_id 做幂等处理。
回调与轮询可同时使用。
7. 图片尺寸与计费档位
size 接受 OpenAI 风格的尺寸串。计费按档位(1K / 2K / 4K),归类规则:

档位	命中的 size
1K	1k;或 宽x高 且最长边 ≤ 1024
2K	2k、2048x2048、2048x1152、2560x1440、1440x2560;或最长边 ≤ 2048
4K	4k、3840x2160、2160x3840;或最长边 > 2048
无法识别的 size 默认按 2K 计费。具体单价以账户计费配置为准。返回对象的 image_size_tier 字段标明本次实际档位。

8. 限制
项	默认值	说明
单用户并发	5	同时排队+生成中的任务数上限;超出 429。可按账户配置调整
每日提交	不限	可按账户配置设置
结果有效期	24 小时	result_urls 过期失效,请及时下载;见 expires_at
同步等待窗口	5 分钟	同步/流式模式最长阻塞;超时 504(任务后台继续)
请求体大小	128 MB	edits 多图场景
参考图(edits)	≤ 10 张	
最小像素值	655360	当请求的尺寸像素小于655360时，最自动放大
最大像素值	8294400	当请求的尺寸像素超过时，会报错
9. 错误处理
9.1 HTTP 状态码(提交阶段)
状态码	含义
400	请求无效:缺 prompt、回调 URL 非法、body 解析失败、被内容风控拦截
403	你的 API Key 不在图片分组,无权限
429	触发限流:per_user_concurrent_max(并发超限)或 per_user_daily_max(日额超限)
503	功能未开启 / 未配置;或 queue_too_long(队列过载,稍后重试)
504	同步等待超时(5 分钟);任务仍在后台执行
502	同步模式下任务最终失败
queue_too_long 示例(503):

{ "error": { "type": "queue_too_long", "code": "queue_too_long",
  "message": "...", "recent_queue_avg_ms": 18000, "max_queue_ms": 10000 } }
9.2 任务级 error_code(status=failed 时)
error_code	含义	是否值得重试
content_refused	模型拒绝(内容/版权/风格等);error_message 含模型回绝原文	否,需改 prompt
safety_rejected	安全系统拒绝	否
rate_limited	上游限流	稍后重试
upstream_5xx / upstream_error	上游临时故障	稍后重试
no_images	上游返回成功但无图	可重试
queue_timeout	排队超时未能调度	稍后重试
client_gone	同步等待窗口内客户端放弃,任务被中止	改异步模式
auth_failed / forbidden / model_or_endpoint_not_found	配置/权限问题	否,请联系技术支持
默认平台会自动重试可恢复错误(超时/限流/5xx/网络抖动),最多若干次;不可恢复错误(内容拒绝、鉴权失败等)立即失败。带 X-Async-Image-No-Retry: 1 可关闭重试。

10. 完整示例
10.1 同步一把梭(最简单)
curl https://img-cn.65535.space/v1/images/generations \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2","prompt":"a cat astronaut, photorealistic","size":"1024x1024"}'
# → 阻塞至多 5 分钟,返回 {"created":..., "data":[{"url":"..."}]}
10.2 异步提交 + 轮询
# 1) 提交(立即拿 job_id)
curl https://img-cn.65535.space/v1/images/generations \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -H "X-Async-Mode: true" \
  -d '{"prompt":"a neon city at night","size":"2048x2048"}'
# → 202 {"job_id":"img_xxx","status":"pending","status_url":"/v1/images/async-generations/img_xxx",...}

# 2) 轮询(每 1-3 秒,直到 done/failed)
curl https://img-cn.65535.space/v1/images/async-generations/img_xxx \
  -H "Authorization: Bearer $API_KEY"
# → {"code":0,"data":{"status":"done","result_urls":["https://..."],...}}
10.3 异步提交 + 回调(免轮询)
curl https://img-cn.65535.space/v1/images/generations \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -H "X-Async-Mode: true" \
  -H "X-Async-Image-Callback-Url: https://your-server.com/hooks/image-done" \
  -d '{"prompt":"a watercolor fox","size":"1024x1024"}'
# → 202 {"job_id":"img_xxx",...};完成后服务端 POST 结果到你的回调地址
10.4 图片编辑(multipart)
curl https://img-cn.65535.space/v1/images/edits \
  -H "Authorization: Bearer $API_KEY" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=replace the sky with a sunset" \
  -F "size=1024x1024"
