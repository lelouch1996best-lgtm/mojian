## 新增「AI 小工具」模块（Hub + 可扩展工具框架）

实现可扩展的小工具导航中心与首个工具「视频超分」（RunningHub 云端 ComfyUI 工作流 API）。

### 架构（零路由改动扩展）
- 入口：首页 header 右上角新增「AI 小工具」ghost 按钮（双 sparkle SVG），`router.push("/tools")`。
- Hub 页 `app/tools/page.tsx`：遍历 `TOOL_REGISTRY` 渲染卡片网格 + 分类 FilterPill 筛选。
- 动态路由 `app/tools/[id]/page.tsx`（server component，`generateStaticParams`）+ `components/tools/ToolPageShell.tsx`（统一头部壳）。
- 注册表 `lib/tools/registry.tsx`：`ToolCategory` 枚举 + `ToolDefinition` 接口 + `TOOL_REGISTRY` 数组 + `getToolById/getToolsByCategory/getEnabledTools`。新增工具 = 写组件 + 数组追加一项。
- 超分工具 `components/tools/super-resolution/SuperResolutionTool.tsx`（"use client"）：状态机 idle→uploading→running→success|failed；未配置 Key 引导卡片+Modal；文件选择+倍率(2x/3x/4x)+提交+轮询+结果预览+下载。

### 后端代理（前端不直连，统一加 Bearer 头转发）
- `lib/runninghub-client.ts`：settings(key=runninghub) + uploadVideoFile/submitSuperResolution/queryRunningHubTask/pollRunningHubTask。超分 APP_ID=`2034560632665677825`；节点 11=倍率(`${scale}.0`)，节点 6=file 输入。
- 4 个路由：`app/api/runninghub/{upload,run,query,download}/route.ts`。upload/run 经 logApiCall 写 api_call_logs（type=video, provider=runninghub）；download 流式转发+`Content-Disposition: attachment` 规避 CORS。

### 关键决策 / 待验证
- ⚠️ **fieldValue 取值歧义**：文档示例 nodeId=6 的 fieldValue 为哈希文件名，但上传响应返回 `download_url` 与 `fileName: openapi/xxxx.png`，三者不一致。当前默认用 `downloadUrl`（完整可访问地址）作为 file 节点 fieldValue；若实际工作流要求 fileName 逻辑路径，改 `submitSuperResolution` 调用处 `fileFieldValue: up.fileName` 即可。需真实 API Key 跑一次链路验证。
- 类型检查（`npx tsc --noEmit`）通过；仅剩 `qiniu` 模块报错属历史遗留（与本次无关）。
