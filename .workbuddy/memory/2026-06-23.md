## 墨间 AI 剧本工具 — COS 上传错误诊断增强

### 问题：COS 上传报 "Access Denied"
- 根因：原本的错误处理只输出 COS SDK 返回的原始 `e.message`，没有提取 `statusCode`、`code`、`RequestId` 等关键字段，用户只能看到“Access Denied”却不知道具体原因。

### 修复
- 重写 `app/api/cos/upload/route.ts`：
  1. 新增 `parseCosError()`：从 COS SDK 错误对象中提取 statusCode / code / message / RequestId
  2. 新增 `cosTroubleshoot()`：根据错误码给出中文排查建议：
     - 403 / AccessDenied → 可能是密钥错误、无写入权限、Bucket 格式不对、Bucket 不存在于该 Region
     - 404 / NoSuchBucket → Bucket 名称或 Region 不对
     - InvalidAccessKeyId → SecretId 无效
     - SignatureDoesNotMatch → SecretKey 填错
  3. 新增 pre-flight `headBucket` 检查：在 putObject 之前先验证凭据和 Bucket 连通性，让用户在"测试上传"时就能得到更早的反馈
- `next build` 通过。

## 墨间 AI 剧本工具 — 火山引擎生成结果自动转存 COS

### 背景
火山引擎 Seedream（图片）/ Seedance（视频）API 返回的 URL 只有 24 小时有效期，过期后链接失效。用户在上一次对话中指出此风险。

### 实现
- 新增 `app/api/cos/transfer/route.ts`：下载远程 URL 文件 → 上传到 COS → 返回 COS 公网 URL。支持自动推断 ContentType 和扩展名，5 分钟超时（兼容视频大文件）。
- 更新 `AssetPreparation.tsx`：
  - 抽取 `generateImageForAsset()` 共享生成逻辑
  - 新增 `transferImageToCos()`：图片生成成功后自动调 /api/cos/transfer 转存到 `ai-script/assets/`
  - 批量生成也复用 `generateImageForAsset()`
  - 转存失败不阻断流程，保留原始 URL 作为 24h 内回退
- 更新 `VideoGeneration.tsx`：
  - 导入 `getCosSettings / isCosConfigured`
  - 新增 `transferVideoToCos()`：视频生成成功后自动转存到 `ai-script/videos/`
  - silent fail 机制：转存失败保留原始 URL
- `next build` 通过。

### 热更新反复失效问题诊断与修复
- **根因**：每次 agent 任务结束跑 `next build` 验证，在 `.next` 留下 production 构建产物。用户后续 `npm run dev` 时，production 缓存与 dev 缓存混在同一目录，导致 dev server 行为异常、HMR 失效。
- **修复**：
  1. 清理 `.next` 目录
  2. 简化 `next.config.mjs` webpack watchOptions：`poll: 500` + `aggregateTimeout: 200` + `ignored: /node_modules/`，去掉多余的 `**/.git` / `**/.next` / `**/.workbuddy` 忽略规则
  3. `package.json` 新增 `predev` 脚本（`rm -rf .next`），每次 `npm run dev` 前自动清理，杜绝残留产物干扰
