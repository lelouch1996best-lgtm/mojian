## 切换数据存储模式为服务端
- `.env.local` 中 `NEXT_PUBLIC_STORAGE_MODE` 从 `local` 改为 `server`。
- 代码已内置 server 模式分支：`lib/storage.ts`、`lib/llm-client.ts`、`lib/image-client.ts`、`lib/video-client.ts`、`lib/cos-client.ts`、`lib/world-settings.ts`、`lib/style-settings.ts` 均通过 `STORAGE_MODE === "server"` 判断走 `apiClient` → `/api/data/*`、`/api/settings/*`。
- 服务端数据库：`lib/db.ts` 用 better-sqlite3，DB_PATH 未设置时默认 `data/mojian-dev.db`（项目根 data/ 目录）。
- 鉴权：`lib/auth.ts`，开发模式（NODE_ENV=development 且未设 STORAGE_TOKEN）自动跳过鉴权。生产环境需设 `STORAGE_TOKEN` + `NEXT_PUBLIC_STORAGE_TOKEN`。
- 用户要求自行启动，未代为运行 dev server。
