### 技术栈

### 核心功能（按用户需求）
1. **首页**：剧集列表（卡片网格）+ 新建剧集 + 删除 + 设置入口
2. **创作页 `/episode/[id]`**：Stepper 两步流程

4. **设置弹窗**：服务商预设（DeepSeek/GLM/自定义）+ BaseURL/APIKey/Model + 测试连接

- 分镜生成用 `response_format: json_object` + `{"shots":[...]}` 包裹格式，`extractShots()` 多重 fallback 解析

## 修复视频提示词未关联资产的问题

用户反馈 Step4 生成的视频提示词没有关联到资产。排查并修复：

### 根因
1. **标注格式**：单 @ 前缀在中文文本中缺少明确的结束标记（如 `@小明坐在` 无法区分标签边界），导致 `extractTags` 正则可能提取错误的标签名
2. **Prompt 不够强硬**：`videoPromptMessages` 只要求"基于资产描述"，但没有强制逐一引用每个资产名称

### 修复
- `lib/prompts.ts` taggingMessages：新增强调规则"**每个 @标签 后面必须跟一个空格或中文/英文标点**"，确保标签边界清晰
- `lib/prompts.ts` videoPromptMessages：system prompt 改为"**必须逐一引用关联资产中的每个实体名称**"，user message 追加"（共 N 个，必须全部在提示词中出现）"
- `lib/utils.ts` extractTags：正则补全更多中文标点结束符（｜|《》〈〉…—·），添加注释说明边界策略
- `components/VideoGeneration.tsx`：
  - `assetByName` 和 `getRelatedAssets` 加 `.trim()` 处理空格差异
