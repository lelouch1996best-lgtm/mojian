# 2026-06-27 工作日志

## 多剧集系列支持

新增 Series（企划）概念，支持创建多个独立的剧集系列。每个系列有独立的世界设定和漫剧风格。

### 类型变更
- `lib/types.ts`：新增 `Series` 接口（id/title/description/order/worldSettings/styleSettings/episodeOrder）
- Episode 去掉 `order` 字段，新增 `seriesId` 字段

### 存储层
- `lib/storage.ts` 重写：Series CRUD（mojian_series）+ `getEpisodesBySeries()` + 旧数据自动迁移（首次加载时建默认 Series 归入旧剧集）
- `lib/utils.ts`：`emptyEpisode(seriesId)` 替代 `emptyEpisode(order)`；新增 `emptySeries(order)`

### 路由重构
| 路由 | 变化 |
|------|------|
| `/home` | 重写为系列列表页（企划网格），移除世界设定/漫剧风格按钮 |
| `/series/[id]` | **新建** 系列剧集列表页（含世界设定+漫剧风格按钮） |
| `/episode/[id]` | 适配 seriesId：前集上下文同系列内，返回按钮回 series 页 |

### 组件变更
- `components/SeriesList.tsx` **新建**：系列卡片网格
- `components/EpisodeList.tsx`：序号改为 index+1
- `components/WorldSettingsModal.tsx`/`StyleSettingsModal.tsx`：新增 `initialSettings`/`onSave` props 支持系列级设置
- `components/ContentExpansion.tsx`：新增 `worldSettings` prop
- `components/AssetPreparation.tsx`/`VideoGeneration.tsx`：新增 `seriesStyleSettings` prop
- `lib/style-settings.ts`：`getActiveStyle`/`getAssetTemplate`/`getVideoStyleSuffix` 增加可选 `seriesSettings` 参数

tsc --noEmit 全部通过。

## Bug 修复

- `normalizeEpisode` 的 `seriesId` 表达式有运算符优先级问题，简化为 `ep.seriesId || defaultSeriesId`
- 迁移排序修复括号优先级
- 剧集编辑页返回按钮改为 `seriesId ? \`/series/${seriesId}\` : "/home"`，防止空 seriesId 导致 404

## 移除旧数据迁移 + 清理脚本

- `lib/storage.ts`：删除 `migrateIfNeeded()` 及所有调用点，保留纯净的 CRUD 逻辑
- `public/cleanup.html`：浏览器缓存清理页面，可一键清除所有墨间 localStorage 数据（episodes/series/settings/models）
