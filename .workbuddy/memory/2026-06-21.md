# 2026-06-21

## 热更新问题修复
- **问题**: Next.js 热更新(HMR/Fast Refresh)不生效
- **根因分析**:
  1. `reactStrictMode: true` 导致 React 18 开发模式下组件双重挂载，状态重置
  2. `.next` 缓存可能陈旧损坏
- **修复**:
  1. `next.config.mjs`: 关闭 `reactStrictMode`，添加 `webpack.watchOptions` 优化 macOS 文件监听
  2. 清除 `.next` 构建缓存
- **需重新执行** `npm run dev` 使配置生效
